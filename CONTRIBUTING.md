# Contributing Guidelines
### Mental Health and Counseling Booking SaaS Platform

We welcome clinical architects, software engineers, and cybersecurity specialists to contribute to the platform.

---

## 1. Code of Conduct

All contributors must uphold the highest standards of professional ethics, respect patient confidentiality, and ensure that health-related code adheres strictly to HIPAA, GDPR, and secure coding practices.

---

## 3. Pull Request Workflow

1. Fork the repository and create a feature branch (`git checkout -b feature/clinical-assessment-enhancement`).
2. Adhere to PSR-12 coding style conventions (`vendor/bin/pint` or `php-cs-fixer`).
3. Write automated unit and feature tests under `tests/Feature` or `tests/Unit`.
4. Ensure all tests pass: `php artisan test`.
5. Verify frontend asset builds: `npm run build`.
6. Submit a detailed Pull Request describing changes and clinical impact.
